# cweto 下载器使用教程：网页版视频解析下载，打开就能用

cweto 下载器是一款**网页版**视频解析下载工具，不用装 App，浏览器打开就能用。支持抖音、快手、B站、小红书、视频号等主流平台，核心操作就是「复制链接 → 粘贴 → 解析 → 下载」。这篇是完整的使用方法。

> **官网地址：https://c.cweto.cn**   （手机、电脑浏览器都能打开）

---

## 一、怎么进入

- **电脑**：用浏览器打开 `https://c.cweto.cn`；
- **手机**：同样用浏览器打开这个地址即可。

进入后就是解析首页，顶部一个大输入框，下面三个按钮：**解析链接 / 批量解析 / 清空**。

> 首次下载不需要注册也能用（游客有 3 次免费），但注册后免费次数更多，见下文。

---

## 二、核心操作：三步下载一个视频

1. **复制链接**：在抖音、快手、B站、小红书、视频号等平台，点「分享」→「复制链接」（复制整段分享文案也行，工具会自动提取网址）；
2. **粘贴解析**：回到 cweto 首页，把链接粘贴进输入框，点「**解析链接**」；
3. **下载**：解析出结果后，点「下载视频」（或「下载全部图片」），文件保存到本地。

全程不用装软件、不用录屏，下载的是无水印原画质文件。

> 小技巧：复制链接后直接在输入框粘贴即可，工具支持从一整段分享文案里自动识别出真正的网址。

## 六、B站视频怎么下（一个特殊点）

B站视频有防盗链校验，普通工具直接下载容易花屏或失败。cweto 针对 B站做了适配，下载时有专门的处理：

- **有 cweto 下载助手扩展**（浏览器插件）时：直接「扩展一键下载」；
- **没装扩展**：先「复制链接与 Referer」，再用 Motrix / IDM / 迅雷等下载工具粘贴下载；
- 也可以点「安装扩展」，按提示装好浏览器插件后就能一键下载。

> 其他平台（抖音、快手、小红书等）直接点「下载视频」即可，无需额外操作。

## 七、常见问题

**Q：复制的是分享文案，不是纯链接，能用吗？**
能。工具会自动从文案里提取出真正的网址，不用手动删文字。

**Q：要装 App 吗？**
不用。网页版，浏览器打开就能用，手机电脑都行。

**Q：游客能下几次？**
游客 3 次，注册后 5 次，VIP 无限次。

**Q：下载的视频占空间吗？**
文件直接下载到你本地（浏览器下载目录/手机相册），网站本身不存你的文件。

**Q：小红书图文能存原图吗？**
能。解析后点「下载全部图片」，整组原图保存。
